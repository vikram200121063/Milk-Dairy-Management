Before your first import
  1. Open each customer's record and set their Milk Machine Code (Edit Customer → Milk Machine Code) to match the Card No / sample ID your machine assigns them. This is how imported rows get matched automatically.
  2. Rows whose machine code doesn't match any customer, or that duplicate an existing entry, are flagged (not silently skipped) on the review screen so you can fix them before confirming.
  3. Rates are always calculated automatically from Fat%/SNF% using your current Rate Configuration — the same formula used for manual "Automatic" entries.
